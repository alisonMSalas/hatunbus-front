# Código de Conducta para Contribuidores

Este proyecto adopta el estándar **Contributor Covenant**. Esperamos que todas las personas colaboradoras actúen con respeto, profesionalismo y cooperación.

## Principios básicos
- Trata a todas las personas con cortesía y empatía.
- Acepta retroalimentación constructiva y evita lenguaje ofensivo o discriminatorio.
- Respeta la diversidad de opiniones, estilos de trabajo y experiencia.

## Alcance
Este código aplica dentro de los repositorios, Issues, Pull Requests, revisiones de código, discusiones y cualquier canal oficial del proyecto.

## Reportes
Si observas un comportamiento inapropiado, repórtalo a **contacto@hatunbus.dev** con el contexto y evidencias disponibles. Todas las denuncias serán revisadas de forma confidencial.
